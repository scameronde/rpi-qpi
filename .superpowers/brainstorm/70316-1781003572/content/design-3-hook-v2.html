Design: SessionStart Hook

Section 3 of 4 — what the hook injects and why

Why a hook?

Without a hook, Claude discovers skills lazily — only when the user types /skill-name. With a hook, Claude is briefed at session start: it knows what skills exist, when to use each one, and invokes them proactively. Same mechanism Superpowers uses for its own skill bootstrap.

Two new files

.claude/hooks/hooks.json
{
  "hooks": {
    "SessionStart": [{
      "matcher": ".*",
      "hooks": [{
        "type": "command",
        "command": ".claude/hooks/session-start",
        "async": false
      }]
    }]
  }
}
.claude/hooks/session-start (bash script)
#!/usr/bin/env bash
# Inject workflow skill awareness
# at every session start

SKILLS_DIR="$(pwd)/.claude/skills"

context="You have workflow skills.

## Available Skills

/mission-architect — greenfield vision
/feature-architect — brownfield feature
/specifier — mission → spec
/epic-planner — spec → epics
/researcher — codebase research
/planner — implementation plan
/subagent-driven-development — execute plan

## When to invoke

Invoke the right skill proactively
when the user's request matches.
Always use /researcher before /planner.
Always use /planner before /sdd."

printf '{
  "hookSpecificOutput": {
    "hookEventName": "SessionStart",
    "additionalContext": "%s"
  }
}' "$context"

What this changes for the user

Without hook With hook
"Research the auth module" → Claude just starts reading files itself Claude recognises the research intent → invokes /researcher Skill automatically
User must know to type "/researcher" Claude surfaces the right workflow step proactively
No guardrails on ordering (user might skip researcher) Hook injects ordering rules: researcher before planner, planner before SDD

Hook vs. CLAUDE.md for this content

CLAUDE.md already documents the workflow — but it's static documentation Claude reads passively. The hook injects a live reminder into every session's context as additionalContext, which Claude treats as active instructions rather than background reading. Both are useful; they serve different purposes.

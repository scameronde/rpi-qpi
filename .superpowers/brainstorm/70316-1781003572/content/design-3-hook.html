Design: SessionStart Hook

Section 3 of 4 — what the hook injects and why

Why a hook?

Without a hook, Claude discovers skills lazily — only when the user explicitly types /skill-name. With a hook, Claude is briefed at session start: it knows what skills exist, when to invoke each one, and can trigger them proactively. This is exactly what Superpowers does for its own skills.

Two files needed

hooks/hooks.json
{ "hooks": { "SessionStart": [ { "matcher": ".*", "hooks": [ { "type": "command", "command": "\"${CLAUDE_PLUGIN_ROOT:-$(pwd)/.claude}/hooks/session-start\"", "async": false } ] } ] } }

It's not Skill vs. Agent files — it's whether an Agent tool call happens

The Key Insight

Whether the orchestrating instructions live in a Command file, an Agent file, or a Skill file doesn't matter for context isolation. What matters is whether the heavy work (file reading, searching, synthesizing) happens inside an Agent tool call — which creates a fresh, isolated context.

A Skill can absolutely spawn isolated Agents for heavy work. The Skill just gives Claude the orchestration instructions in the main context — the actual work still runs in fresh subagents.

Which stages actually need isolation?

Stage What it does Context cost Isolation needed?
mission-architect Conversation with user Low No — Skill is fine
feature-architect Conversation + light scan Medium Spawn scan agents
specifier Read mission → write spec Low No — Skill is fine
epic-planner Read spec → write epics Low No — Skill is fine
researcher Read many files, search patterns Very high Yes — keep as Agent
planner Read research + code → write plan High Yes — keep as Agent
implementation (per task) Edit files, run tests High SDD: fresh agent per task ✓

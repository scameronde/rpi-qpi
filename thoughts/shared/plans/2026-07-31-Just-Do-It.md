## Design Overview

- **The gate lives upstream.** `/change-architect` settles `route:` during its existing convergence check. `direct` requires both: `## Open Questions for Fact-Finder` is the literal `none — nothing must be established before the change`, and `## Acceptance Criteria` holds exactly one entry. Anything else is `full`, and `full` is the default.
- **The elicitation must stay uncorrupted.** A new Non-Negotiable forbids mentioning, hinting at, or offering the cheaper route while asking what the research must establish. Without it the gate measures intent to skip rather than size of change.
- **`/just-do-it` is the second exit.** Refuse unless `route: direct`; refuse if a Record already exists; apply `/implement`'s branch rule. Read only what the change needs, change it in the main session, dispatch exactly one reviewer in a fresh context, allow one fix round, then commit the change and its Record together.
- **Three bounds contradict the claim after admission.** More than ~5 files needed, or more than one implementation site → stop before changing anything. Diff over ~50 changed lines → discard and stop. Second review failure → discard and stop. Every stop writes `status: abandoned` and routes to `/fact-finder`.
- **The Record mirrors the plan/STATE pairing but is write-once**, so it needs no mutability carve-out — the store's universal default is already correct for it.
- **Discovery runs by name derivation, not by category.** `thoughts/shared/plans/` is one `thoughts-locator` category though it holds plans and STATE files; `changes/` stays one category for the same reason, keeping the count at 10.


**Change Record filename:** `thoughts/shared/changes/YYYY-MM-DD-[Change-Name]-RECORD.md` — same base name as the brief it belongs to.

**Change Record frontmatter — all five keys:**
```yaml
---
date: YYYY-MM-DD
just-do-it: [identifier]
change-brief: "thoughts/shared/changes/YYYY-MM-DD-[Change-Name].md"
status: complete | abandoned
review: passed | passed-after-fix | failed | not-reached
---
```

**Change Record body — four required sections, plus a fifth exactly when `status: abandoned`:**
`## Outcome`, `## Files Changed`, `## Acceptance Criterion`, `## Review Verdict`, and `## Abandonment` (abandoned only — names the bound that tripped and where the work went).

**The three bounds:** ~5 files read · exactly 1 implementation site · ~50 changed lines.
